# PC Builder & Service Calculator

Cyberpunk/neon interactive web calculator built with **HTML**, **CSS**, and **Vanilla JavaScript** for estimating PC build and service pricing, approximate completion time, and submitting order requests.

## Live Demo
Open the live app on GitHub Pages: `https://okupchak1-code.github.io/pc-builder-calc/`

## Features
- Interactive selection of PC build and service options with real-time price calculation
- Estimated turnaround / service time calculation
- Cyberpunk / neon UI styling with responsive layout
- Built-in order modal for submitting requests

## Tech Stack
- HTML5 (`index.html`)
- CSS3 (`style.css`)
- Vanilla JavaScript (`script.js`)
- Hosted via GitHub Pages

## Local Run
1. Clone or download the repository:
```bash
git clone [https://github.com/okupchak1-code/pc-builder-calc.git](https://github.com/okupchak1-code/pc-builder-calc.git)
```

2. Open `index.html` in your browser (or run a local static server).
